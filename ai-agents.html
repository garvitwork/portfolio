01 LangGraph · MLOps · Agentic AI

AI Agent Scout — Supply Chain Disruption Early-Warning Agent

Multi-agent LangGraph pipeline that scores shipment disruption risk with XGBoost and turns it into a plain-language, explainable recommendation via Gemini — deployed end-to-end as a live API and frontend.

An agentic AI system that monitors shipments, scores disruption risk and predicted delay using ML models tracked via MLflow/DagsHub, and generates explainable recommendations through a 3-agent LangGraph pipeline — a MonitorAgent that pulls shipment and supplier context from a cloud MySQL instance (Aiven, SSL-enforced), a RiskAgent that scores the shipment from the latest MLflow-registered XGBoost models using a lightweight, single-shipment SQL feature build built for memory-constrained cloud inference, and a RecoAgent that turns the scores into an action-oriented recommendation with Gemini. The full data-to-model path is orchestrated as a versioned DVC pipeline DAG, live weather and news signals feed the feature pipeline alongside a 180K+ record historical shipment dataset, and the agent pipeline is served through a FastAPI backend on Render with a Streamlit ops dashboard for batch review.

Why it matters

Enterprise supply-chain risk platforms are built for six-figure budgets, leaving mid-market manufacturers and distributors — who need early warning the most — reliant on spreadsheets and reactive firefighting. This system flags at-risk shipments before they're late, with every recommendation grounded in the model's own top contributing features for full auditability. The risk classifier reaches 70.2% accuracy (ROC-AUC 0.757) and the delay forecaster runs at 0.98 days MAE — both versioned in the MLflow model registry with a fully reproducible pipeline.

02 LangGraph · Fraud Detection · Explainable AI

Claim-Sentinel — Autonomous Insurance Fraud Detection & Adjudication Agent

A three-agent LangGraph pipeline that scores insurance claims for fraud with LightGBM + SHAP, then auto-adjudicates each one with an LLM-written, auditable adjuster note.

An agentic fraud-detection system built for a regulated, high-friction vertical where a bare accuracy score isn't enough — claims must be explained, decisions must be auditable, and low-risk claims should clear automatically while high-risk ones get escalated with a written justification. A cloud MySQL schema (Aiven, SSL-enforced) holds policyholders, claims, decisions, and a full audit log; a live enrichment step fuzzy-matches claimed vehicle details against NHTSA's vPIC API as a fraud signal. A class-weighted LightGBM classifier scores each claim, with SHAP surfacing the top contributing factors per prediction. A 3-agent LangGraph pipeline — IntakeAgent, FraudRiskAgent, AdjudicationAgent — then turns that score into a decision: an approve/escalate verdict plus a natural-language adjuster note generated from the SHAP factors via a Groq-hosted LLM, both written back to MySQL for a full, traceable audit trail. The whole data-to-model path is a 5-stage, reproducible DVC pipeline tracked via MLflow on DagsHub, served through a FastAPI backend on Render, with a static "case-file" style frontend — rubber-stamp verdict, signed SHAP bars, and the LLM-written note.

Why it matters

Most portfolio fraud-detection projects stop at "train a classifier, report accuracy." Insurance claims need more: regulators and adjusters need to know *why* a claim was flagged, and every automated decision needs a traceable record. Claim-Sentinel demonstrates that full loop — data infrastructure through ML, explainability, agentic adjudication, and deployment — end to end. The fraud classifier runs at a ROC-AUC of ≈0.83 (0.59 recall / 0.56 precision on the fraud class), tracked and versioned in MLflow with a fully reproducible pipeline.
