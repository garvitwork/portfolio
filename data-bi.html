01 Healthcare Analytics · MLOps · Power BI Flagship

MediPulse AI — Hospital Operations & Patient Risk Intelligence Platform

Hospital operations platform predicting readmission risk, bed demand, stockouts, and burnout — with an AI-written weekly briefing.

Full-stack analytics platform spanning a MySQL data warehouse, Python ETL, five machine learning models, an LLM narrative layer, and a 7-page Power BI dashboard — predicting patient readmission risk, bed demand, supply stockouts, and staff burnout across a hospital network, then having an AI write the weekly executive briefing.

Why it matters

Most healthcare analytics projects predict one thing in isolation. MediPulse AI connects four domains through one shared warehouse — a bad flu season raises occupancy, which raises overtime, which raises burnout risk, which feeds back into readmissions — and reasons across all of them instead of four spreadsheets that never talk to each other. Every threshold is percentile-based relative to the model's own score distribution rather than a fixed cutoff, so segmentation stays meaningful as the underlying data shifts.

05 Data Pipeline · LLM · Power BI

Mandi Price Arbitrage & Farmer Advisory System

Live, unattended pipeline that detects daily crop-price gaps across Maharashtra mandis and turns them into a plain-language farmer advisory using an LLM.

End-to-end data pipeline connecting a government open-data API, MySQL, Python automation, and Power BI into one unattended system — pulling fresh mandi prices daily for Onion, Tomato, and Potato, computing the best and worst market per commodity, and using the Groq LLM API to turn that computation into a one-sentence recommendation a farmer could act on. All three stages run on a daily schedule via Windows Task Scheduler with pipeline-reliability logging, and Power BI stays connected live to MySQL across three report pages plus a drill-through detail page.

Why it matters

Farmers often sell at the nearest mandi even when another market 50–150 km away is paying 100%–300% more for the same commodity on the same day — a real, quantifiable income loss that most farmers have no easy way to see because prices across dozens of markets are never compared in one place. This pipeline closes that gap daily, automatically, without anyone running it by hand.
